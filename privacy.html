개인정보 안내

‘달의 안부’는 계정 없이 카드 리딩을 사용하는 앱입니다. 현재 앱에는 광고·분석 SDK와 자체 서버로 정보를 전송하는 기능이 없습니다.

리딩 기록

최근 리딩 6회는 기기의 앱 저장 공간에 저장됩니다. 앱의 ‘지난 리딩 → 기록 지우기’에서 삭제할 수 있습니다. 앱 데이터 삭제나 앱 제거 시에도 삭제됩니다. 앱 자체의 클라우드 백업은 사용하지 않습니다.

사용자 지정 이미지

사용자가 직접 선택한 카드 이미지는 앱 안에서 표시하며 서버에 업로드하지 않습니다. 이 이미지 연결은 앱을 다시 시작하면 사라질 수 있습니다. 카메라, 위치, 연락처 접근은 요청하지 않습니다.

외부 링크

출처 등 외부 사이트를 열면 해당 사이트의 개인정보 처리방침이 적용됩니다. 리딩 기록과 사용자 지정 이미지를 외부 링크에 첨부하지 않습니다.

기본 카드 이미지

원본 Rider–Waite–Smith 카드 78장을 앱에 포함합니다. 이미지 출처와 권리 관련 기록은 앱 배포 자료의 출처 문서에 보존합니다. 위키미디어에서 카드별 권리 확인을 마친 이미지로 교체하는 작업은 아직 완료되지 않았습니다.

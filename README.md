# 달의 안부 · Moonlit Tarot

질문을 마음에 떠올리고 카드를 섞어 펼치는 모바일 웹 앱입니다. 질문을 글로 입력할 필요는 없습니다.

## 실행

Python 3 및 Node.js 18 이상. 외부 패키지 설치는 필요 없습니다.

```sh
cd /workspace/tarot.app
npm run dev
npm test
```

포트 3000에서 실행합니다. 파일 하나로 이용할 때는 `python3 scripts/export.py` 실행 후 `dist/moonlit-tarot.html`을 브라우저로 여세요.

## 리딩

- 3장: 과거 / 현재 / 앞으로의 흐름
- 4장: 현재 상황 / 장애물 / 조언 / 예상 흐름
- 비교: 왼쪽 3장과 오른쪽 3장(상황, 조언, 흐름), 가운데 핵심 조언 1장
- 6카드 타임라인: 위쪽 전체 주제 1장, 아래 왼쪽부터 시간 순서 5장

Fisher–Yates 셔플로 78장을 섞고 중복 없이 배분합니다. 버튼으로 반복해서 섞을 수 있으며, 다시 펼칠 때도 새로 섞인 덱을 사용합니다. 타임라인의 위치는 상대적인 흐름이며 특정 날짜 예측이 아닙니다. 정방향만 지원합니다.

메이저 22장 및 마이너 56장 각각의 키워드·해석·실천 조언을 카드 도감에서 확인할 수 있습니다. 검색과 수트 필터를 제공합니다. 최근 리딩 6회를 브라우저에 저장하며 클릭해 다시 볼 수 있습니다. 기존 한 장 뽑기 초안의 기록은 별도 보존하지만 새 화면에서 표시하지 않습니다.

## 유니버셜 웨이트 이미지

원본 라이더–웨이트–스미스 이미지 78장을 assets/cards에 포함합니다. 유니버셜 웨이트 재채색판과는 다른 원본입니다. 출처와 라이선스는 assets/cards/SOURCES.md 및 LICENSE.txt를 참조하세요. 정방향 해석은 자체 작성 문구입니다. 다운로드 HTML에도 이미지 78장을 모두 포함합니다.

기본 이미지를 다른 카드 이미지로 바꾸려면 앱의 이미지 설정에서 사용 권한이 있는 파일들을 선택해 기기 내부에서 연결합니다. 업로드 전송은 하지 않으며 새로 열 때 다시 선택해야 합니다. 파일명은 카드 ID와 같아야 합니다. 확장자는 브라우저에서 지원하는 이미지 형식입니다.

- `major-0.jpg` ~ `major-21.jpg`: 바보부터 세계 (힘 8, 정의 11)
- `minor-0-0.jpg` ~ `minor-0-13.jpg`: 완드
- `minor-1-0.jpg` ~ `minor-1-13.jpg`: 컵
- `minor-2-0.jpg` ~ `minor-2-13.jpg`: 소드
- `minor-3-0.jpg` ~ `minor-3-13.jpg`: 펜타클
- 마이너 순위: 0 에이스, 1~9는 2~10, 10 페이지, 11 나이트, 12 퀸, 13 킹

타로는 자기 성찰용 콘텐츠입니다. 로그인, 서버 저장, 역방향, AI 종합 리딩은 포함하지 않습니다.

## 이미지로 스프레드 선택

드롭다운 대신 네 개의 배치 그림 버튼을 제공합니다. 시간의 흐름(3장), 상황과 해답(4장), 두 갈래 선택(7장), 시간의 여정(6장)입니다. 선택된 버튼은 테두리와 체크 표시로 구분하며 키보드로도 선택할 수 있습니다.

## 아이폰에서 앱처럼 사용

`python3 scripts/package_site.py`로 HTTPS 정적 호스팅용 `dist/site/`와 `dist/moonlit-iphone-site.zip`을 생성합니다. 사이트 루트 및 하위 경로 호스팅 모두 지원합니다. 이미지 78장, 홈 화면 아이콘, 웹 앱 매니페스트와 서비스 워커를 포함합니다. 최초 온라인 방문 시 앱 파일을 캐시하며, 캐시 완료 후에는 오프라인 재실행이 가능합니다. 사용자 지정 이미지 선택은 세션 동안만 유지됩니다.

공개 HTTPS 주소를 Safari로 열고 공유 → 홈 화면에 추가 → 추가를 누르세요. 웹 앱으로 열기 옵션이 표시되면 켜세요. 다운로드 HTML이나 ZIP 미리보기는 아이폰 설치 방법이 아닙니다.

간단한 배포: https://app.netlify.com/drop 에 로그인한 뒤 ZIP을 해제한 `site` 폴더(바로 안에 index.html이 있는 폴더)를 업로드합니다. 서비스가 발급한 HTTPS 주소를 사용합니다. ZIP 다운로드 자체는 배포가 아닙니다. 현재 대화 환경에서 GitHub API 접근이 Forbidden으로 거부되어 실제 공개 배포는 완료하지 못했습니다.

서비스 워커 캐시 버전은 scripts/package_site.py의 CACHE를 변경해 갱신합니다. 테스트는 모바일 크기의 Chromium에서 수행하며 실제 iOS 홈 화면 설치 확인과 구분합니다.

## 추가 리딩

- 오늘은 한 장: 오늘의 메시지 1장
- 켈틱 크로스(Celtic Cross): 현재, 교차하는 영향, 근본, 과거, 목표, 가까운 미래의 십자 6장 및 나의 태도, 환경, 희망과 두려움, 예상 흐름의 오른쪽 세로 4장. 가운데 두 번째 카드는 가로로 겹치며 역방향을 의미하지 않습니다.

## Wikimedia Commons 교체 작업 — 현재 미완료

현재 이미지는 기존 GitHub 출처이며, Commons에서 확인한 파일로 표시하지 않습니다. 네트워크에서 `commons.wikimedia.org` 및 `upload.wikimedia.org` 접근이 허용되어야 합니다.

1. `python3 scripts/import_commons.py --check-only`: 78개 파일별 제작자·권리 표시를 API로 확인합니다. 없는 파일명이나 확인 불가 권리는 오류로 중단합니다.
2. `python3 scripts/import_commons.py`: 원본 JPEG와 Commons SHA-1을 비교하고, 78장이 모두 검증된 후 교체합니다. 기존 파일은 dist의 별도 백업에 보존합니다.
3. 각 파일의 페이지, 원본 URL, 제작자, 권리 이름/URL, 사용조건, 제한 표시, 메타데이터 원문, 조회일, 해시를 `assets/cards/commons-attribution.json` 및 `COMMONS_ATTRIBUTION.md`에 기록합니다.
4. `python3 scripts/package_site.py`는 확인된 출처를 앱에 포함합니다. 각 카드의 리딩 및 도감 상세에 원본·권리 링크가 표시됩니다. 새 이미지 교체 시 캐시 버전을 갱신하고 테스트 후 배포합니다.

현재 네트워크 403으로 78장 원본/권리 조회가 완료되지 않았고, 이 교체 작업은 아직 공개 사이트에 배포하지 않았습니다.

## Android / Google Play

Capacitor 기반 Android 앱 프로젝트를 android/에 추가했습니다. 앱 자산 78장을 로컬 번들로 포함하며 원격 웹사이트를 로드하지 않습니다. `npm run android:sync` → `npm run android:debug`로 개발 APK를 생성합니다. 정식 AAB 서명과 출시 준비는 [출시 문서](docs/play-store/RELEASE.md)를 참조하세요. Play Console 업로드/등록은 별도입니다. 개인정보처리방침 및 소개 자료는 초안입니다.

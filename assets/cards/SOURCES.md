# Card artwork

Original Rider–Waite–Smith (1909), illustrated by Pamela Colman Smith, commissioned by Arthur Edward Waite. These scans are NOT the later Universal Waite recoloring.

Source: https://github.com/metabismuth/tarot-json (cards and tarot-images.json). Source project identifies scans as original RWS and notes US public-domain status. Its historical README's EU warning predates the end of Smith's life + 70-year term (Smith died 1951). Original artwork is public domain in life + 70 jurisdictions from 2022. Source repository MIT notice is retained in LICENSE.txt.

Local filenames map source m00–m21 to major-0–major-21; w01–w14, c01–c14, s01–s14, p01–p14 to minor suit indices 0, 1, 2, 3 and rank indices 0–13, respectively. Source manifest: https://raw.githubusercontent.com/metabismuth/tarot-json/master/tarot-images.json

The four spread SVG diagrams in ../spreads are original application UI artwork.
